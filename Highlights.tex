\section{Highlights}
\begin{itemize}
\item Anthropomorphic design has a moderate positive effect on user outcomes
\item Communication style produces the strongest effects on user experience
\item Personality traits produce large positive effects on user outcomes
\item Visual appearance strengthens trust, while demographic identity improves user experience
\item Effects vary by attribute and outcome and are reduced by publication bias
\end{itemize}
